<h3>📡 IoT-Scanner — Adaptive IoT Network Mapper</h3>

<p>
A C-based IoT network scanner currently focused on discovering and
identifying devices on a local network using low-level network probing.
</p>

<p>
The current stage focuses on exploring network devices and collecting
basic identification information. The project is still under development,
with future plans for deeper device analysis and security assessment.
</p>

<h4>🔎 Current Focus</h4>

<ul>
  <li>ARP-based device discovery</li>
  <li>ICMP probing for active hosts</li>
  <li>Basic SNMP enumeration</li>
  <li>MAC vendor classification</li>
  <li>Raw-socket networking in C</li>
</ul>

<h4>🧠 Future Direction</h4>

<ul>
  <li>Device fingerprinting</li>
  <li>Behavior analysis</li>
  <li>Risk assessment</li>
  <li>Device isolation</li>
  <li>Automated response mechanisms</li>
